# \## Descripción

# 

# Aplicación de consola en Java para gestionar clientes, libros y préstamos de una biblioteca.

# 

# La información se almacena en memoria utilizando `ArrayList`, sin utilizar una base de datos.

# 

# \## Cómo ejecutar

# 

# 1\. Abrir el proyecto en NetBeans.

# 2\. Compilar el proyecto con Maven.

# 3\. Ejecutar `Main.java`.

# 

# \## Funcionalidades

# 

# \- CRUD de Clientes

# \- CRUD de Libros

# \- Registro de préstamos

# \- Registro de devoluciones

# \- Listado de préstamos activos
